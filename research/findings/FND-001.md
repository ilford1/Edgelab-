# FND-001 — Illustrative supportive result placeholder

This node demonstrates how supportive evidence is preserved and linked. It contains no observation, dataset output, estimate, or market claim.

A real finding must include experiment ID and version, dataset ID and version, sample dates, effect size with uncertainty, baseline comparison, leakage checks, cost assumptions, known failures, and artifact paths sufficient to reproduce the result.

Status: **illustrative-not-evidence**.
